03Where XP comes from

    Level curve

    Level L needs 50 × L × (L − 1) XP

    Each level costs 100 XP more than the last. Daily use reaches level 10 in about a week and level 50 in about seven months.

    Each day with a turn adds one to your streak. Every seven days earns a rest day, up to two, which covers a day off.

    Thirteen badges to find.

    Each one is worth 50 XP and 25 coins.

      06Under the hoodSystems

      Small, careful, and yours.

      Every session agrees.

      Plan limits arrive with each reply, and each session hears only its own. The mod keeps the newest reading in one small file, so every open session shows the same 5-hour and weekly figures within ten seconds.

      It updates itself, carefully.

      Every six hours the mod asks GitHub's public tag list for a newer release. Press the button and it fast-forwards its own folder to that one tag. It never moves a repository it was copied into, and never overwrites your changes.

      The terminal gets text bars.

      In the terminal the band is plain text, with a face that matches his mood. It gives things up in the same order as the desktop band when the window narrows.

      Nothing about you leaves your machine.

      Your level, coins and the last readings live in one small file under your Claude Code config, shared by every session and project. The only network call is that tag check, with no account and no token. Set CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC to turn it off.

      08InstallTwo steps

      Clone it, point Claude Code at it.

      01Clone the repo

      Anywhere works. The update button keeps this folder current.

      git clone https://github.com/lucassimzq/claude-usage-mod.git ~/claude-usage-mod

      02Load it

      Add it to the env block of ~/.claude/settings.json. This covers the desktop app too.

      {
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "~/claude-usage-mod",
    "CLAUDE_CODE_PLUGIN_DIR_WATCH": "1"
  }
}

      Try it for a single terminal session without touching your settings.

      claude --plugin-dir ~/claude-usage-mod

      Good to know

      • NeedsClaude Code 2.1.286 or later. The 5h and 7d bars need a Claude subscription.
      • Shows inThe terminal and the desktop app's Code tab. It doesn't show on claude.ai, where mods can't load.
      • /usage-hudHides or shows the band, and remembers your choice.
      • /usage-hud statsLevel, XP, streak, coins and badges.
      • /usage-hud shopOpens the shop as a panel you click through.
      • /usage-hud updateChecks for a new version now and installs it.
