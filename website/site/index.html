03 · Levels

Hitting the limit is a win.

The crab levels up as you work: XP for every turn, a daily bonus, streaks with rest days, and a payout the moment a window reaches 100%. Pacing a window well pays the most.

    Coins

    Coins buy things in the shop. Level unlocks are free: the scarf at level 3, the beanie at 5, up to the golden shell at 50. Cache tokens don't count, so prices stay sane.

    04 · Shop

    Tokens become hats.

    Every 1,000 tokens Claude writes earns a coin. In Claude Code, /usage-hud shop opens this as a panel. Here, pick something to try it on, then buy it with the coins this page's crab has saved. He wears it everywhere on the page.

    05 · Under the hood

    Small, careful, and yours.

    No account, no server, nothing about you sent anywhere. The mod runs in your own Claude Code and keeps its state in one small file.

    Fig 5.1Shared readings
    Point at a session
    Every session agrees

    Plan limits arrive with each reply, and each session hears only its own. The mod keeps the newest reading in one shared file, so every open session shows the same 5-hour and weekly figures within ten seconds.

    Fig 5.2Updates
    Move to scrub
    Updates, fast-forward only

    Every six hours the mod asks GitHub's public tag list for a newer release. Press Update and it fetches that one tag and fast-forwards your clone. If git can't, it changes nothing.

    07 · Install

    Two minutes to install.

    You need Claude Code 2.1.286 or later. The band shows in the terminal and in the desktop app's Code tab. The 5-hour and weekly bars need a Claude subscription.

    1. Step 1

      Clone the repo

      $ git clone https://github.com/lucassimzq/claude-usage-mod.git ~/claude-usage-mod
    2. Step 2

      Load it in every session

      Add the folder to the env block of ~/.claude/settings.json. Watching the folder lets the desktop app pick up an update without a restart.

      {
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "~/claude-usage-mod",
    "CLAUDE_CODE_PLUGIN_DIR_WATCH": "1"
  }
}
    3. Or

      Try it for one terminal session

      $ claude --plugin-dir ~/claude-usage-mod

    Commands

    • /usage-hudHide or show the band. New sessions remember it.
    • /usage-hud statsLevel, XP, streak, coins and badges.
    • /usage-hud shopOpen the shop panel to buy, wear or take off.
    • /usage-hud updateCheck for a new version now and install it.
    • ↻Refresh the figures (r in the terminal).

    It doesn't show on claude.ai: mods load from your own machine's Claude Code. Set CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC to turn off the update check.
